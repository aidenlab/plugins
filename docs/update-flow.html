Each app needs its own refresh to pick up a new plugin version

Where a version lives. A Geenee version is the version field in the four manifests on main, nothing else. Merging the PR that bumps it publishes it. A geenee--v<version> tag is optional and only builds the release file, so a version can be live with no tag. The bare v1.0.0 to v1.3.2 tags and releases from October 2026 belong to the retired juicebot plugin, not to Geenee.

The version in the manifests is what tells an app there's something new. If the files change but the version doesn't, a sync finds nothing to install. That's why docs/maintaining.md says to bump the version in all four manifests on every change.

The release ceremony, in order

  1. In the PR, bump version in all four manifests: plugins/geenee/plugin.json, plugins/geenee/.claude-plugin/plugin.json, and the geenee entry in both marketplace catalogs.
  2. Merge. Marketplace users can update from this point on.
  3. On an up-to-date main, validate and tag: 
    git checkout main && git pull
claude plugin validate . && claude plugin validate ./plugins/geenee
claude plugin tag plugins/geenee --push
  4. Check that the release workflow passed and that the GitHub release geenee--v<version> has geenee.plugin attached: gh run list --workflow release.yml -L 1.
  5. If the change matters to people now, tell them to Sync (or to run the update command). Org admins also have to re-sync or re-upload.

Open questions to check in the apps

Where is a manual Sync in the Claude desktop app now?The November 2026 app moved the plugin screens. The old path (Customize → Plugins → aidenlab → Sync) is gone, and the new one hasn't been walked through. Each new version on main was also seen to uninstall Geenee in Claude desktop without any message, three times in November 2026. The install steps carry a recovery line for this.
Does Claude Code update third-party marketplaces on its own?As I understand it, automatic updates are on by default only for Anthropic's own marketplaces, and users switch them on per marketplace in /plugin. The README also says that adding aidenlab in Claude's settings covers Claude Code. Both are worth checking on a test machine.
Do Codex or ChatGPT desktop ever refresh a marketplace in the background?docs/maintaining.md assumes it's manual (codex plugin marketplace upgrade). Not yet seen either way.
Does a change to the Connector settings need the Connect step again?A skill or CLI change doesn't touch the Connector. A changed server address or authentication might need users to Connect again under Connectors on Geenee's page. Test this before shipping such a change.
How a user can confirm their versionThe plugins page in Claude, and the plugin list in Claude Code and Codex, should show the installed version next to geenee. After a sync it should match the version in the manifests.
