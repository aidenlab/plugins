Installing Geenee: a cheat sheet

Geenee used to reach people as a bare server address they pasted into their connector settings. It now reaches them as a plugin in a marketplace: one install brings the server and a skill that teaches the assistant how to use it, and updates follow. This page shows how the pieces fit and what to do in each app.

Claude Code, Codex and ChatGPT: one sentence

The address serves INSTALL-PROMPT.md from the aidenlab/plugins repository: instructions written for the assistant, not for a person. Editing that file changes what every assistant does next time; nothing needs redeploying.

In Claude Code, Codex, or Codex inside the ChatGPT desktop app, paste this and the assistant installs everything itself. Each time it asks for permission, click Approve:

Set up Geenee for me: fetch https://geenee-install.3dg.io and follow its instructions for the app you are running in.

In claude.ai, the Claude desktop app and Cowork no prompt can install anything: adding a plugin is an account setting, and a chat cannot change those. Pasted there, the sentence only gets you the list of clicks below. Plain ChatGPT chat cannot install Geenee at all; use Codex in the ChatGPT desktop app.

Geenee is installed only from the marketplace, in every app, because only a marketplace install gets updates. The server address is never added by hand.

What gets installed, and where

Geenee needs nothing installed on anyone’s computer. The server runs on the internet; the viewers open in a browser tab. The plugin is a handful of small text files that tell the app where the server is and how to use it.

claude.ai, the Claude desktop app and Cowork

Plugins are added to the account, not the app, so this one setup also reaches Claude Code the next time it starts signed in (/login forces it). On Team and Enterprise an Owner may first need to allow user-added marketplaces and add Geenee’s connector for the organization.

Follow these steps to install Geenee.

  1. Go to Customize → Plugins → +Add → Add marketplace → Add from a repository. Enter this URL: aidenlab/plugins
  2. Click Sync
  3. You will be on the Discover tab. Click Add (Not +Add).
  4. Select the Connectors tab. Connect → Continue → Add

Things to know:

  • You need a paid plan.
  • If you see Sync automatically next to aidenlab, turn it on. That’s how Geenee’s updates reach you.
  • If you still have the old juicebot plugin, or a connection to juicebot-mcp.3dg.io or geenee-dev.3dg.io, remove it. Otherwise you’ll get duplicate tools.

To check it worked: start a new chat and ask Claude to open Geenee. It calls open_geenee and gives you a link to a page with IGV, Juicebox and Spacewalk tabs. Keep that browser tab open while you use it. If a step fails, report it at github.com/aidenlab/plugins/issues with a screenshot.

Claude Code

Already there if the Claude account has Geenee. Otherwise:

claude plugin install geenee --marketplace aidenlab/plugins

Inside a running session, /plugin install geenee --marketplace aidenlab/plugins then /reload-plugins does the same.

Codex

codex plugin marketplace add aidenlab/plugins
codex plugin add geenee@aidenlab

ChatGPT

  1. Open the ChatGPT desktop app → click Codex.
  2. Paste the one sentence above.
  3. Each time Codex asks for permission, click Approve.
  4. When it finishes, it gives you a message. Paste that into a new chat.

Plain ChatGPT chat cannot install Geenee.

Is it working?

Ask, in a new conversation:

Open Geenee. In Juicebox, load the ENCODE GM12878 in situ Hi-C map at the HOXA cluster and add the gene track. In IGV, go to HOXA1 and add the GM12878 CTCF ChIP-seq track.

The assistant answers with a Geenee link. Open it: one page with IGV, Juicebox and Spacewalk tabs. The page must stay open while you work; the assistant drives it from the conversation. Three states are worth telling apart when something is missing:

Updates

A new plugin version reaches people when their app refreshes the marketplace. Claude’s apps and Codex can do this automatically; by hand:

claude plugin marketplace update aidenlab && claude plugin update geenee@aidenlab
codex plugin marketplace upgrade aidenlab

Changes to the server itself, such as a new tool, need no update at all: every app asks the server for its tools afresh.

Replacing juicebot

The plugin id is permanent: it is how every install finds its updates. That is why juicebot could not simply be renamed, and why geenee is a new plugin rather than a new version.

An earlier plugin, juicebot (shown as JuiceBot, later as Geenee), is retired and no longer updated. Anyone who has it should remove it and install geenee; the one-sentence setup does both. By hand:

claude plugin uninstall juicebot@aidenlab
claude plugin marketplace update aidenlab
claude plugin install geenee@aidenlab

In claude.ai, remove JuiceBot on the plugins page and any JuiceBot connector. In ChatGPT, remove any JuiceBot, geenee-dev or hand-added Geenee server, then install through Codex.

Words

MCP serverThe program that offers the tools, here geenee.3dg.io/mcp. It is the same with or without a plugin.
ConnectorAn app’s saved connection to an MCP server.
SkillA Markdown file of know-how the assistant reads when a conversation needs it. Written by hand; only its tool reference is generated.
PluginA folder that packages a server address and a skill under one name and version.
MarketplaceA GitHub repository listing plugins. Added once; its plugins are then installed by name.

For the maintainer: publishing a change

  1. Edit on a branch: the skill in plugins/geenee/skills/geenee/, and after a tool change the generated reference (scripts/gen-tools-md.py).
  2. Raise version in all four manifests: both plugin.json files and the geenee entry in both marketplace.json files. Never change the name.
  3. Check: claude plugin validate . && claude plugin validate ./plugins/geenee, then scripts/test-cli.sh.
  4. Merge, then tag the release; the workflow attaches geenee.plugin to it.
claude plugin tag plugins/geenee --push
